## 🆘 Troubleshooting Common Issues

**Problem: The application won’t start or the browser doesn’t open**
Restart your computer, then try again. If it still fails, make sure your Windows is updated to the latest version.

**Problem: I don’t see current prices for a particular cryptocurrency**
Check your internet connection. Ghostfolio fetches live data from public APIs. Some obscure coins may not be in the database.

**Problem: The dashboard looks blank or charts aren’t showing**
Make sure your browser is updated to a recent version (Chrome, Edge, or Firefox). You can also try a different browser.

**Problem: I forgot my data or accidents happened**
Since this is anonymous, there’s no password or cloud backup. We recommend occasionally using the "Export Data" feature (look for it in settings) to save a backup file to your computer.
